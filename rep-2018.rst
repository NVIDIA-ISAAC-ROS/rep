Abstract
========

This REP proposes a new native type to represent tensors as a block of memory with a shape that can be optionally backed by an external memory manager.


Motivation
==========

THE PROBLEM: Accelerator caches, need tensor to be a first-class native type as a successor to standard array types for DNN policy-driven robots.

****
-Embodied AI agents need tensors for policy-driven robots using DNN inference
-NITROS solves this for CUDA, but need a more common way for developers to optionally pick up acceleration on the platform they are running on.
****

High-level Goals
----------------

- Provide a native way to represent tensors across all interfaces from client libraries through RMW implementations.
- Make available a set of common operations on tensors that can be used by all interfaces.
- Enable accelerated implementations of common tensor operations when available at runtime.
- Enable accelerator memory management backing these tensors when when availale at runtime.
- Optimize flow of tensors for deep neural network model inference to avoid unnecessary memory copies.
- Allow for backwards compatibility with all non-accelerated platforms.
